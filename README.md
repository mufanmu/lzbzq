# ⚡ 梁子变祖器

> 风评再低谷，也无人以 ÷ 称他——AI 圈皆知，÷ 永远只属于那一个人。

**社区风评阻尼器 · 每日一票 · 娱乐向**

拖动滑块，给「梁文锋的风评」打一个分。你的每一票都会推动电阻，但电阻总会阻尼回落到社区均值——这就是变祖器的物理。

## 🎮 玩法

1. 按住滑块（lz 切图）左右拖动到目标位置，松开
2. 确认「当前选中」的数值与档位，点 **确认投票**
3. **每天一票**，北京时间 0 点结算，昨日结果写入事件记录（仅档位变化才记录）
4. 当日满 10 票，解锁**今日热评**——得票最多的档位梗句

## 🏷 档位谱系（左 → 右）

| 档位 | 数值 | 梗 |
|---|---|---|
| 😇 梁神 | 100 | 震惊四座，全网封神 |
| 🙏 梁圣 | 83 | 梁圣的恩情还不完！ |
| 🧧 梁文锋叔叔 | 67 | 早上领国补，晚上领美股 |
| 😐 梁子 | 50 | 食言太多，吃成了梁子 |
| 🕳 牢梁 | 33 | 牢字辈三幻神，恭迎牢梁归位 |
| 🥀 小难梁 | 17 | 小难梁拿不出大赢鲸 |
| 🖤 梁西皮 | 0 | 互联网的尽头是抽象 |

每个档位 4 条随机梗句，投票确认时随机弹一条；满格（全员梁神）触发核弹彩蛋，归零触发 ÷ 之守护。
